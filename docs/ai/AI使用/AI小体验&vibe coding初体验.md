## 一、我的背景
我大二人文社科的学生，在进入大学高强度使用AI工具和最近接触vibe coding完成第一个project之后，对AI使用有了一些小理解，想写一篇小文章总结记录一下。

### 二、AI工具们
#### 1、Gemini pro
~~我的Google账号是初二就开始用的老号了，所以各种切IP都不会风控，也是非常非常幸运地体验到了1年的Gemini pro了。~~
 Gemini在去年12月份左右的时候是真的实打实的最强，各个意义上的，只不过最近真降智了（当然啦，我没去试过AI studio的API有没有降智），情绪价值给的太足了，无论你问什么它都会先肯定你，可以把它当作夸人给情绪价值的工具。
 Gemini干活的话，只有nano banana有明显的优势。
 Gemini CLI的话没有深度体验（用Gemini  3.1 pro跑了一个plan大概花了20%的pro额度，Google这点还是比较小气），Antigravity没有用过，不置评价。
 对了，Google家大业大，还有NotebookLM这个玩意，这个确实是个神迹，可以把课程所有的参考资料喂进去，然后总结思维导图之类，用来速通考试真的很棒；也可以使用它做PPT，PPT也可以输入提示词，生成的效果还是不错的，不过我最近不怎么用它做PPT了，因为发现了更好的方法（后文。

#### 2、ChatGpt Plus
Open AI的风控没那么严格，所以在闲鱼上搜AI、Pro、Plus等关键词都可以找到20人民币左右/月的Gpt plus充值（不知道是怎么做到的，应该也是拼车吧）。
Gpt就是特别特别地稳，而且额度量大管饱，在高强度用了三天codex跑完一整个project之后（大概236Mtokens），大概花了一周的额度，而且好像自动刷新了（？）也不知道为啥，总之就是量大管饱。
ChatGpt回答问题会比Gemini不给那么多情绪价值，比较理性，回答的话短句分点很多（如果不去手动设置偏好的话），在用了几次觉得不对劲之后，我就在personalization里的custom instruction里设置了禁止滥用短句和分点。之后的回答确实是高质量了很多。
而且ChatGPT提出来的方案大多都是可行的、比较稳定的，这点也体现在codex里面。

#### 3、Claude Pro
除了额度少、价格高（pro一个月20刀，跟GPT一样，但是GPT可以拼车，会便宜非常多）、公司排华乱封号之外几乎找不到任何缺点。
关于Claude的注册和订阅：我在注册之前，专门去把万人共用ip的梯子换掉了，换成了vless + reality + vps + v2ray的自建方案（有点玄学，不知道IP质量是不是真的会引发风控，因为最近Claude code的CLI源码泄漏之后，有看到一些分析封号原因的（好像IP不是那么重要？）
注册的时候用了接码平台+Google账号，用了几天free没被封之后，才去研究怎么充值。
在我研究一圈之后，发现虚拟信用卡很容易被封、我手头没有安卓手机无法使用Google play、拼车容易被封、闲鱼买也容易被封（而且封了退款可能到不了自己手上）。所以就选择了Apple美区ID+礼品卡的充值。
**关于美区ID**：我一开始想去买一个，但好像感觉不安全，然后发现在中国大陆用+86的手机号也是可以注册的，具体来说就是使用苹果手机Safari浏览器无痕浏览模式，关掉梯子，打开苹果账号注册网页，填信息，地区填美国，邮箱用gmail或别的国外邮箱，地址用地址生成器就行。然后在App Store里登陆这个账号，如果显示地区还是中国大陆，就手动改成美国。然后支付宝改定位买礼品卡即可。
在正常只使用chat，不使用Claude code的情况下，Claude pro的额度是完全足够使用的。但如果使用Claude code，那就会烧的非常非常快，估计只能做一个plan+implement一个plan，最后debug一下，一个Session（4小时刷新一次limit）的额度就没了。。。
Claude确实非常非常好用，具体体现在：
1、说话有人味，简单明了，给的情绪价值没有gemini那么足，但是是真的能干好活的，写得课程论文质量真的很高而且很有人味。用来读文献的话我没尝试过，因为~~志不在科研~~
2、很多的skill可以用，比如，做docx讲义、读pdf、做ppt等，都很好用。我就用这些功能，在Claude里建了一个家教备课的project，原来花两三小时才能备好的课，现在只要把参考资料拍个照，写写提示词，一份精美的讲义就出来了，有一种切实感受到AI已经真的能当成生产力工具的感觉。![[Pasted image 20260402003048.png]] ![[claude1.png]]

#### 4、GitHub Copilot
copilot pro可以通过GitHub学生认证免费领取，虽然现在学生优惠被砍了很多。。
不过copilot的使用体验还是不错的，主要体现在vs code里面的插件，代码补全，agent也支持比较新的模型，额度也量大管饱（就是Claude模型被砍了）。氪金的话10刀一个月可以用最新模型（GPT5.4之类），~~但还不如直接用codex的~~
copilot也有chat模式，在vs code或GitHub上都可以用，不过我没试过（~~AI工具真的好多，试不过来）~~

#### 5、Deepseek
DS当初爆火确实是有原因的，不是因为能力有多强，而是因为价格很低很低的同时性能不错，主打一个性价比，我现在使用DS的场景主要是：充个十来块的API，在沉浸式翻译插件里面接API用，翻译可读性确实比Google Translate好挺多。

#### 6、豆包
豆包的优势就是手机应用可以打电话，拿来练英语口语还可以。其他没体验过，包括最近出的专家模式我也没来得及去试，不置评价。听说seedance还不错，不过我也没有生成视频的需求，有兴趣的同学可以去试试（？

### 四、vibe coding
在我高强度冲浪怎么充值Claude的时候，知乎老是给我推送vibe coding，我就想着，既然Claude pro和GPT plus我都充了，Gemini CLI和GitHub copilo也有一些额度，那我不去尝试一下不是可惜这些额度了（？
然后我就开始想，我想做一个怎么样的project。我想到了时间/任务管理的工具，因为之前用过进度条/structure/很多todolist软件，但都不是很符合我的心意。
然后突然有个灵感冒出来，我想做一个以menubar（状态栏的按钮）为核心，以周为单位的任务管理工具，因为我的时间确实是以周划分的，而且我很喜欢menubar，之前一些软件弃坑的原因就是，我老是要打开软件才能设置/查看，或者要点到桌面查看小组件，如果有一个能够常驻状态栏的任务管理软件就好了。
我先让Claude chat给我提了一些creative idea，然后就下载打开Xcode kuangkuang开干。当然了，我不会swift语言，也没用python做过大项目，只能全部让AI帮我写。
一开始，我写了个readme，在里面写下了我的初步想法，然后打开claud code，让它给我丰富我的readme，并进行第一版的开发。在一通一通尝试后，我完成了第一版（省略跟Xcode博弈的几个小时，第一次用apple的ide，确实搞不明白...），确实跑起来了，基础的任务添加删除、任务文件夹管理都实现了，在我一个又一个想法冒出来的同时，Claude的额度也没了......
然后我开始转战codex，跟codex鏖战了两天，终于把想法全都实现了，具体来说就是
✅胶囊周数、节日、纪念日、生日，
✅以及完成后会有小奖杯![[Pasted image 20260402102853.png]]
✅还有像GitHub贡献度一样的热力统计图
✅和系统的reminder（提醒事项）app的连接
✅还有一些Liquid Glass的效果
✅让AI帮我画了个logo，codex甚至直接帮我裁切成不同大小的![[Pasted image 20260402103318.png]]

#### 期间的一些小感悟：
1、我有时候会在想，AI老是从头手挫一个功能，还可能失败，我就不能让它拿别人写好的东西用吗？然后我就试了一下，让它先搜索GitHub的类似功能的实现，再往下跑，确实准确、稳定而且快速了很多
2、git版本管理真的很重要，我又用Xcode又用vs code、Claude code又用codex，每个工具自己都有git，然后就很不清楚，我一开始也想着一个小项目没必要管那么清楚，但随着后面功能变多，再加上AI有可能生成一些不想要的东西，真的后悔没有一开始好好管理git......
3、遇到问题要不断地去搜索学习，论坛上看到的新东西要学会尝试着用在自己的项目里（比如我在逛GitHub刷到一个PUA AI的skill![[Pasted image 20260402103635.png]]，能让AI更卖力干活，在我碰到一个debug了三四轮对话还没解决的问题时，我就用了这个，居然出人意料解决了）![[Pasted image 20260402103705.png]]
4、使用coding确实能极大程度提高写prompts的能力，要说清楚方法、目标，有什么样质量的提示词就有什么质量的产出
5、上下文很重要，你不能让AI忘记你的项目是干啥的，所以要维护好readme和Claude.md或者Agents.md这些给AI讲什么东西需要做什么东西不能做的文件

### 五、结语
写在最后：
在用coding的时候，我也在想，如果我能看懂AI怎么写的，我是不是能给出更加清晰的方向和指示呢，在知乎上看到一句，“你只不过是不会开车的路线规划员，在给AI司机说要怎么开”，果然还是得自己懂一个领域，才能在这个领域用好AI。
写了很多很多AI工具，AI确实是在重塑我们的生活，但是我也会给自己留一份自留地，比如，我的obsidian和备忘录一定不接受接入AI，我们确实还是要保留自己的文字输出能力，把自己不喜欢的课程论文交给AI，但我们有感而发的文字、日记、总结，还是原滋原味来得好。
