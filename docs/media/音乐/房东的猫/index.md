# 房东的猫
[房东的猫](https://weibo.com/u/3908615569)是我最喜欢的音乐人。我们结缘于2022年9月份，那时候我应该还在上高二。

房东的猫是唱作小组合，由王心怡（[@红鼻子小黑](https://weibo.com/u/1692961311)）和吴佩岭（[@少年佩](https://weibo.com/1952463355)，虽然现在佩岭ID改了，但我似乎还是更加愿意称她为少年佩～）两人组成。

她们的乐队建立于2013年11月19日
![[index-1785832861118.webp]]
似乎每个重要的节点，这条微博都会被翻出来，它好像是一个锚点，见证着我们我们的一路走来。“大家好，我们是房东的猫弹唱小组合”，世青巡演每次到这一part到时候都格外令人想哭，可能是因为过了这一part就要结束了，可能是因为见到了她们始终纯粹的初心，也有可能是这也映照了我们的初心吧。
