# missing-semester
missing-semester是MIT开的一门关于计算机入门的课程，知识密度极高，囊括了关于命令行、vim、IDE、调试、性能、版本控制、打包、coding agent等内容，是计算机入门的不二之选。
在学习计算机，比如一门编程语言时，很多时候不是搞不清楚算法/语言本身，而是不知道shell是什么，用什么命令来运行，怎么控制版本，怎么配置环境之类。搞清楚这些是很重要的，这也是missing-semester这门课开设的初衷。
幸运的是，我在[CSDIY](csdiy.wiki)中发现了这门课程，并耐心地学了下去，对我之前零碎的知识带来了很系统的梳理。顺带一提，CSDIY真的是一个很伟大的网站。
